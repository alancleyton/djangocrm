# DjangoCRM
A simple CRUD app made with Django Framework

# Install and run the project locally
.1 Clone this repository
```bash
  git clone https://github.com/alancleyton/djangocrm.git
```

.2 Go to the project and activate the virtual environment. You can use `venv` or `virtualenv` to create your virtual environment

.3 Install the project requirements
```bash
  pip3 install -r requirements.txt
```

.4 Run all database migrations
```bash
  python3 manage.py migrate
```

.5 Run server locally
```bash
  python3 manage.py runserver
```
